# Traxure for Cursor

[Traxure](https://traxure.com) checks every day that each of an artist's
releases is live on the streaming stores and on the right artist profile.
This plugin connects Cursor to your Traxure account so you can ask about your
music in plain words.

[![Add to Cursor](https://cursor.com/deeplink/mcp-install-dark.png)](https://cursor.com/install-mcp?name=traxure&config=eyJ1cmwiOiJodHRwczovL3RyYXh1cmUuY29tL21jcCJ9)

## Set up

1. Install the Traxure plugin from the Cursor Marketplace (or use the button
   above, which adds the same server).
2. Cursor shows Traxure under MCP servers. Choose **Connect** (or
   **Needs login**).
3. Your browser opens. Sign in to Traxure and choose **Allow**.

Nothing else to set up: no API key, no settings. Any Traxure account can
connect; UPC/ISRC lookup needs a Traxure plan.

Server address, if you add it by hand: `https://traxure.com/mcp`
(Streamable HTTP, sign-in with OAuth).

## Things to ask

- "Is all of my music still live on Spotify and Apple Music?"
- "What went wrong with my catalog this week?"
- "Which of my artists have a release missing from a store?"
- "Write the email to my distributor about the missing release."
- "Make a link in bio for my new single with my Instagram and merch link."
- "Look up UPC 196626XXXXXX: which stores have it?"

## Tools

| Tool | What it does |
| --- | --- |
| Overview | Your workspaces, artists, unread alerts and setup progress |
| Alerts | Recent alerts: a song that may be taken down, on the wrong artist profile, not live on release day, changed details |
| Release status | For each release, which stores have it live and which are missing it |
| Release problems | Open problems on an artist's releases |
| Distributor letter | A ready draft to your distributor about a missing release. You send it yourself |
| UPC & ISRC lookup | The release behind a code and the stores that have it (plan members) |
| Smart links | Your smart link and link-in-bio pages, addresses and 30-day clicks |
| Edit smart link | Make or change a smart link page (the only tool that changes anything) |
| Getting paid | Your getting-paid checklist |
| Plan | Your plan, renewal date and how much of it you use |
| Free scan | A link to the free catalog scan for any artist |

It can't change your plan or payment details, remove artists, delete your
account or send anything for you. It only sees the workspaces you belong to,
with the same permissions you have on the website. Store checks cover the US
versions of the stores.

## Disconnect

Remove Traxure from Cursor's MCP settings, or sign out of Traxure everywhere.
